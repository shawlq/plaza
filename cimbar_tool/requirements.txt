# Python dependencies for cimbar_tool.
#
# The batch encoder currently uses only the Python standard library, so this
# file is intentionally empty and remains safe to install with:
#   python -m pip install -r requirements.txt
#
# Important:
# - pip will not download or install cimbar.exe.
# - libcimbar is currently not published as a pip package.
# - The official libcimbar release provides Web assets such as cimbar_js.html,
#   but not an official Windows cimbar.exe.
#
# External runtime dependency for automated PNG export:
# - libcimbar command line encoder (cimbar.exe on Windows), built or provided
#   separately.
#   https://github.com/sz3/libcimbar
